# Физика 9 клас – подготовка за националното есенно състезание

Статичен уеб сайт (HTML/CSS/JS, без зависимости), оптимизиран за мобилни устройства.

- **Теми** – кратка теория, формули, решени задачи, типични грешки и трикове (`topic.html?t=…`)
- **Всички формули** – дълъг списък с търсене, филтри и печат (`formulas.html`)
- **Тест** – въпроси с обяснения (`practice.html`)
- **Съвети** – стратегия, план за подготовка (`tips.html`)

Съдържанието е в `js/data.js` (теми, формули, въпроси). Отваря се директно като `index.html` или чрез GitHub Pages.
Темите, маркирани като „разширение“, може да не са в програмата – сверявай с официалната обява.
